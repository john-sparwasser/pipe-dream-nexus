Super Mario World – choose a bank

The community SMWDisC disassembly, split per bank and rendered as browsable logs in the style of PJ's Super Metroid bank logs. Every JSR/JSL/branch target and every named table is a link; each routine lists its callers; hardware registers show their name on hover. 3359 sections across 16 banks, 3359 with English names and summaries.

$00 – Boot, main loop, NMI/IRQ, game-mode dispatch, DMA, SPC upload, controller, status bar, Mario state & block interaction

$01 – Core sprite engine: main loop, status dispatch, init/main tables, shared sprite subroutines, most enemy mains

$02 – More sprite mains, generators, cluster/extended sprites, sprite spawning from level data

$03 – Sprite mains $A1–$C8, bosses (Reznor, Big Boo, Bowser), bank-local utility copies

$04 – Overworld engine: game mode 0E, player path movement, event/path reveal, level names, OW sprites

$05 – Level loading: header decode, object stream decode, layer 2/3, scroll commands, level pointer tables

$06 – Level Layer-1 object data (no code)

$07 – Overflow level data, sprite tweaker tables, InitSpriteTables, sine table, misc sprite support

$08 – Graphics (GFX00–GFX0F, 4bpp/3bpp tiles)

$09 – Graphics (GFX10–GFX1F)

$0A – Graphics (GFX20–GFX2F)

$0B – Graphics (GFX30–GFX31, Mario/Yoshi tiles)

$0C – OW Map16 definitions, cutscene/credits/enemy-parade engine, OW Layer-1 tilemaps

$0D – Map16 16×16 definitions, object draw-routine dispatch + tile-writing primitives, credits enemy names, freespace

$0E – Music data + SPC700 sound engine (uploaded to the APU at boot)

$0F – BRR sample data for the SPC700
